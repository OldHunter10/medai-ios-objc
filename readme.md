# MedAI iOS (Objective-C)

An iOS application designed to assist with symptom analysis using intelligent input processing and structured results presentation.  
Built entirely in Objective-C, this app is intended for further expansion into clinical or educational AI tools.

---

## Features

- User-friendly symptom entry and result output
- History tracking with quick re-entry
- Clipboard support for copy and paste
- Basic error handling and UI feedback
- Lightweight utility modules for string handling and debugging

---

## Planned Features

- AI-based symptom-to-diagnosis inference engine
- Multi-language interface (e.g. English, Chinese)
- Dark mode and UI customisation
- Result sharing and export options
- HealthKit / Medical data integration
